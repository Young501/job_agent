直接安装

每个平台各保留一份 Worker。

  1. 1
    确认 Tampermonkey 已启用

    Chrome 中需要安装并启用 Tampermonkey 扩展。

  2. 2
    点击“安装 / 更新”

    为 LinkedIn、Indeed 和 SEEK 分别打开安装确认页。

  3. 3
    确认安装或更新

    同名 Worker 会覆盖旧版本，不会另外创建重复脚本。

  4. 4
    运行统一预检

    返回每日任务，Worker 会领取任务并填写平台搜索条件。

“安装 / 更新”会替换同平台的旧版 Job Agent Worker，不会覆盖原有 LinkedIn/Indeed/SEEK helper。复制代码保留为浏览器未唤起 Tampermonkey 时的备用方式。
